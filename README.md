# STARWARS_AUTOCALLS

Predicts `avg_duration_months` for structured autocallable products, combining
RFQ history, market volatility and underlying reference data.

## Repository structure

```
code/
├── data/
│   ├── raw/              rfqs.csv, daily_volatility.csv, underlyings_reference.csv
│   └── processed/        modeling_table.csv (generated by build_features.py)
├── models/                model.joblib (generated by scripts/run_training.py)
├── notebooks/              exploratory analysis (EDA)
├── scripts/
│   └── run_training.py    one-command entry point: raw CSVs -> trained model.joblib
├── src/starwars_autocalls/
│   ├── config.py           shared paths and constants
│   ├── data/                loaders.py (read + validate raw CSVs), integration.py (merge/aggregate)
│   ├── features/            build_features.py
│   ├── modeling/            train.py, evaluate.py
│   └── api/                 FastAPI inference service (main.py, schemas.py)
└── tests/
```

## Run training from the source CSVs

    uv run python scripts/run_training.py

Reads `data/raw/*.csv`, builds the modeling table, fits the RandomForest
pipeline and saves it to `models/model.joblib`.

## Save the trained model artifact

Training (above) already saves the artifact. To only rebuild the intermediate
modeling table, without training a model:

    uv run python -m starwars_autocalls.features.build_features

This writes `data/processed/modeling_table.csv`.

## Run the inference API locally

    uv run uvicorn starwars_autocalls.api.main:app --reload

Then, e.g.:

    curl http://127.0.0.1:8000/health
